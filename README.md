# Dice and Duels

A real-time 1v1 PvP dice game. Roll your dice, assign them to attack and defense, activate your class skills, and outlast your opponent before the timer runs out.

Currently a work in progress — new classes, skills, and polish on the way.

**Try it here:** https://dice-and-duels.onrender.com/

## Built with

- React + Vite
- Node.js + Express + Socket.IO
